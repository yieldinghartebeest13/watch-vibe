## Installation
- [Download](https://github.com/yieldinghartebeest13/watch-vibe/releases/latest) both .apk files from the '<i>Assets</i>' section.
- Install `WatchVibe.apk` on your watch. [Learn how](https://www.howtogeek.com/how-to-sideload-apps-on-your-wear-os-smartwatch/).
- Install `WatchVibeControl.apk` on your smartphone.
